# v0.2.0 代码与页面适配检查

检查基线：`v0.2.0`（`e0642f7`）。以下修复已纳入 `v0.2.1`；需等待该标签的镜像构建成功后升级，现有 `v0.2.0` 镜像不会自动包含这些修复。

## 已确认的问题与修复

| 优先级 | 问题与影响 | 修复及验证 |
| --- | --- | --- |
| P1 | 私有购物清单的商品经归档或分类修改后写入无归属的全局历史，其他成员可通过常买、联想获知商品信息 | 推荐与分类记忆改为读取当前用户可见清单的商品和归档记录；清单改为私有或删除后重新过滤。回归覆盖成员、设备、共享范围变更和分类隔离 |
| P1 | 用户自行修改密码后，其他浏览器的旧会话仍可操作账号；密码校验期间发生重置，也可能签发旧密码会话 | 保留改密请求的当前会话，撤销其余会话并断开 SSE；校验结束后复查密码哈希。测试覆盖旧会话失效、当前会话保留、旧密码拒绝及并发重置 |
| P2 | 并发修改两名管理员的角色和密码时，异步哈希前的管理员数量检查可同时通过，最终没有管理员 | 将检查放到哈希完成后的同步写入之前；并发回归确保始终保留一名管理员 |
| P2 | 同一秒内连续备份复用同名旧文件，重置前的自动备份可能缺少刚写入的数据 | 文件重名时增加递增后缀，每次生成新快照。测试读取第二份快照确认新数据，并检查最近 7 份保留和路径校验 |

主要代码：[购物服务](../apps/server/src/services/shopping.ts)、[账号服务](../apps/server/src/services/users.ts)、[登录服务](../apps/server/src/services/auth.ts)、[备份服务](../apps/server/src/services/backup.ts)。未修改数据库结构或既有迁移文件。旧 `shopping_history` 表保留兼容，但不再作为推荐来源，因此已删除清单中的旧全局推荐不会继续出现。

## 页面适配

检查设备宽度：360、390、768、820、1024、1440 CSS 像素；卡片额外覆盖 320 像素。检查主题：`liquid-glass-light` 与 `liquid-glass-dark`。

| 模块 | 检查内容 | 处理结果 |
| --- | --- | --- |
| 首页 | 默认卡片、编辑状态、卡片库；时钟 S/M、天气 S/M/L | 天气与时钟按卡片宽度缩放字体、图标和留白；手机保留最小字号。极窄的中号天气卡片显示四天预报，避免负温度文字溢出 |
| 日程与待办 | 月、周、日、列表视图及日程编辑弹窗 | 检查各宽度的布局；实际提交新日程和待办成功 |
| 购物 | 清单列表、条目、编辑清单、超市模式 | 修复手机及平板横向溢出；触屏平板直接显示编辑和删除按钮，键盘聚焦时也可见；实际添加及勾选商品成功 |
| 设置 | 个人、外观、家庭、大屏、数据、添加成员与重置确认弹窗 | 窄屏操作区可换行，备份文件名可折行；生成备份后检查真实文件条目布局。未在页面测试中执行重置 |
| 登录与大屏 | 登录、注册、初始化表单、配对表单及大屏看板 | 检查手机、平板布局；平板图标导航补充可访问名称 |

本次审查时的时钟布局在 768 像素宽度下约从 48px 放大至 87px；默认中号天气温度同样随容器放大。360/390 像素手机上的中号卡片仍保留约 48px 的主要数字。字号使用卡片容器宽度计算，编辑尺寸和挂墙模式同样生效。此后 v0.2.1 进一步改为带秒数、本周日期条及可选指针表盘的时钟，已另行检查手机、平板与明暗主题；本段字号为审查时的测量记录。头像外圈裁切修复也已检查文字与图片两种头像。

## 验证范围

- `bun run check`：106 个测试通过，455 个断言，覆盖 20 个测试文件。
- `bun run build`：通过，主入口 JS gzip 约 137.6KB，低于项目 150KB 预算。
- 使用真实运行的本地服务和独立测试数据库，执行页面交互、截图及横向溢出检查；覆盖最新 Chrome 与 Chromium 132（对应此前反馈的 360 浏览器内核）。
- 全模块矩阵分别覆盖 252 和 138 个页面状态，未发现脚本异常或整页横向溢出。另检查 320–1440 像素下的五种天气/时钟尺寸组合、负温度数据，并在两个内核的手机和平板触屏模式下实际打开购物条目编辑弹窗。
- 天气页面使用固定晴天及负温降雪数据，便于复查字体和排版；本次没有把天气上游服务可用性作为通过依据。
- 初始化表单展示使用未初始化状态模拟，其他页面使用实际接口；登录、新建日程、待办、商品操作及备份执行了实际请求。

这些是浏览器视口和触屏能力模拟，不是 iPad Safari、Android 各厂商浏览器的实机验收；本次也未进行长期运行或高并发压力测试。
